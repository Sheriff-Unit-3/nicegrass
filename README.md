# Nice Grass

[![luacheck](https://github.com/Sheriff-Unit-3/nicegrass/actions/workflows/luacheck.yml/badge.svg)](https://github.com/Sheriff-Unit-3/nicegrass/actions/workflows/luacheck.yml)
[![reuse](https://github.com/Sheriff-Unit-3/nicegrass/actions/workflows/reuse.yml/badge.svg)](https://github.com/Sheriff-Unit-3/nicegrass/actions/workflows/reuse.yml)

Removes dirt from sides of MTG's grass. Adds artificial turf.

## Features

* Artificial Grass
* No dirt on sides of grass

## Dependencies

* Luanti/Minetest v0.4.10
* MTG provided mod `default`

### Optional

* [`xcompat`](https://github.com/mt-mods/xcompat/)
